Línea del Tiempo: Evolución del HTML

Versiones clave de HTML

  • HTML 1.0 (1991): Experimental, solo texto e hipervínculos.
  • HTML 2.0 (1995): Primer estándar oficial (RFC 1866).
  • HTML 3.2 (1997): Soporte para tablas y applets.
  • HTML 4.01 (1999): Separación de contenido y estilo (CSS).
  • XHTML (2000): HTML escrito como XML.
  • HTML5 (2014): Semántica, multimedia nativa, APIs modernas.
