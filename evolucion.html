Línea del Tiempo: Evolución del HTML

1991 HTML 1.0

Creado por Tim Berners-Lee en el CERN. Solo 18 etiquetas para texto, enlaces y listas. Sin imágenes ni formularios. Base conceptual de la Web.

1995 HTML 2.0

Primera especificación oficial (RFC 1866). Estándar del IETF. Incluye formularios e imágenes. Base común antes de las extensiones propietarias.

1997 HTML 3.2

Estándar del W3C ("Wilbur"). Unifica tablas, applets y flujo de texto alrededor de imágenes. Elimina la complejidad matemática de HTML 3.0.

1999 HTML 4.01

Mejora accesibilidad, internacionalización y soporte para CSS, scripts y multimedia. Ofrece DTDs: Strict, Transitional y Frameset.

2000 XHTML

HTML reescrito bajo reglas XML: sintaxis estricta, etiquetas cerradas, atributos entre comillas. Busca código limpio y portable.

2014 HTML5

Estándar moderno del W3C. Introduce semántica (<article>, <nav>), multimedia nativa, APIs (Canvas, Geolocation) y diseño responsivo.
